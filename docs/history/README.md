# Point-in-time records

These documents describe the state of the project on the day they were written.
They are **not maintained** and should not be read as current documentation —
figures, file paths, component names and checklists in them may since have
changed. They are kept because they record why things were built the way they
were.

For current documentation start at the [README](../../README.md).
